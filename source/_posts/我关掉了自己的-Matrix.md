description: "本文描述了作者在尝试使用 Matrix 客户端与朋友进行即时通讯过程中所经历的一系列技术困境和随后的软件探索过程。最初，作者尝试使用 SchildiChat 和 FluffyChat 等移动端客户端与朋友进行聊天，但很快遇到了账号验证失败、密钥作废以及客户端不兼容等问题，导致 Matrix 交流受阻。在尝试重新部署 Matrix 实例的过程中，作者也遇到了技术上的挫折，包括图片日志的发送问题和部署环境的限制。鉴于 Matrix 的不便，作者将目标转向寻找局域网 TUI（Text User Interface）聊天工具。然而，AI 搜索结果显示，市面上的 TUI 工具要么缺乏开源仓库，要么质量低下，无法满足大众需求。作者对这种“需求多、供给少”的现象感到困惑，指出虽然 GUI 聊天工具（如飞鸽传书和茶话会）历史悠久，但优秀的 TUI 局域网聊天软件极其稀缺。作者还遇到了茶话会这类软件的运行问题，例如在 Mac 上需要通过命令行赋予权限，质疑其“开箱即用”的说法。最终，作者总结出一种矛盾的现象：需要 TUI 的局域网聊天工具反而倾向于 GUI 优先，而需要 GUI 的 Matrix 却难以达到微信那样的图形化体验。作者认为，AI 应该将精力投入到重塑和改进这些缺乏的聊天软件上。在经历了长时间的技术折腾后，作者最终放弃了这些复杂的即时通讯尝试，转而使用更简单的非即时通讯方式，并以一个关于时间错乱的幽默感结束了这段技术探索之旅。"
---

编者本来跟小芬在 Matrix 上聊得好好的，小芬问编者：“有没有什么移动端的 Matrix 客户端？”编者说：“有的，比如编者就在用的 SchildiChat。”于是第二天下午，小芬配置好了 FluffyChat 发起聊天。编者当时看到小芬并没有验证，就好心提醒他，让他把账号认证做了。小芬说自己在外面，暂时接触不到电脑，于是这件事情就这样搁置了。晚上的时候睡了一觉，突然接到小芬的 Matrix，小芬又登录了新的 Matrix 客户端。也就是说小芬现在都不知道，哪个是本密钥，原本的密钥早就被客户端作废了。现在小芬相当于抱着个死号，但编者想起来自己也有一个 Matrix 账号，还通过搜索知道了 iamb 可以向好友发起验证邀请。

谁知刚发过去，就提示编者说客户端不兼容。这意味着，小芬根本没法完整 Matrix 验证。首先是手机就不兼容了，电脑编者就不想确认了，估计就算兼容小芬也不会。记得当初搞多客户端验证，都是自己一点一点摸索来的。一是小芬的账号彻底废了，二是小芬在聊天中发了图片。大家要知道，编者并不是在 Serverless 主机上部署的 Matrix，在自己的机器上部署是需要网络的。小芬也是迷迷糊糊地把图片日志发过来，结果刚发完才想起来不能发。删掉了这个实例之后，编者去重新部署了 Matrix，但大家都知道，编者是尤其讨厌循环的一个人。编者干脆就不想做了，去寻找有没有什么局域网 TUI 聊天工具，结果都是二流的开源项目。

AI 帮编者找到了 Python 模块网上的 TUI 聊天工具，但编者发现这个工具连个开源仓库都没有。AI 又帮编者找到了一个 JS 做的聊天工具，这次虽然是有仓库了，但是仓库里根本没有用户在使用，也没有图片来展示这个项目。编者去问 AI，为什么这些大众的需求，结果给编者的却是些三瓜俩枣就能糊弄的东西？AI 回答说，虽然编者常能在 B 站上看到“新的局域网聊天工具”，但它们都是图形化的工具；如果需求是图形化工具，那选择就非常多了。像飞鸽传书这类老牌局域网聊天工具，还有茶话会这种开源的局域网聊天工具。软件历史的长河中，几乎是滚滚流淌着多位开发者的心血。但几乎就是没有 TUI 的，令人难以理解这其中。

你看 TUI 的需求非常多，开源的需求非常多，就连局域网聊天的需求也非常多，但就是没看见过优秀的 TUI 局域网聊天软件。编者把茶话会下载下来了，刚下载下来就提示编者说无法运行，问了 AI 说是 Mac 的风险检测。于是乎，编者又用命令行给了这个应用运行权限，你说这种需要给命令行才能用的，到底是怎么说自己开箱即用的，难道这个软件的主要客户不是 Mac，大伙都没有提出要签证吗？但无论怎么说，也没 Matrix 更加友好吧？编者跟小芬配置 Matrix 的时候，要么就是配置文件复制两行代码，要么就是全程图形化填框下一步。但你说这个世界怎么那么奇怪呢？很多东西就好像走错了一样，让人看了一头雾水的。

需要 TUI 的局域网聊天，反而是 GUI 优先；而需要 GUI 的 Matrix，反而做不到微信这种图形界面。编者觉得现在 AI 既然那么强大，那么这种聊天软件真的是下乡的第一对象，需要这些 AI 大神来重塑。最后编者寻思也没啥可折腾的了，就卸载掉了这些软件。本来不想用 QQ 还想跟陌生好友保持即时联系，最后也只能使用邮箱进行非即时的联系了……也是，本来大伙就不认识，要那么即时通讯干什么呢？编者又不是找客户。因为折腾了那么久，编者也必须要爽一下嘛。于是编者去问小芬，今晚还玩《我的世界》吗？小芬十分诧异，说：“今天不是周日吗？明天编者得上学……”编者这才想起来，昨天居然已经是周六了；今日周日，但很晚了。

折腾了那么久，突然理解那些电视剧里的反派，为什么好端端的突然想毁灭人类了（开玩笑的）……
