最近我更换了自己的代码编辑器。我在 Codium 上虽然过得很好，Aider 也是我信得过的 Agent 工具，但我在写作方面可就大大受了挫折。新编辑器的字体和老编辑器不一样，我真得老老实实分工写作软件和代码编辑器了。我之前对于这两者都是不分的，我写代码的时候用的是 Trae，平时写文章用的也是 Trae，Obsidian 是我平时放在电脑里面看都不看一眼的软件。但现在这种情况，我又去 Obsidian 的官网把 Obsidian 下载回来了，拿来专门写作用。毕竟，一个正经的所见所得 Markdown 编辑器，味道可比 Codium 那种代码编辑器爽多了。估计也是之前在 Linux 兴趣群里混久了，看里面神人用 Code 当笔记软件习惯了，自己也下意识拿 Code 当作笔记软件。

Obsidian 里面不是可以换字体和主题的吗？我换了一个 Minimal 主题，还把字体换成了跟自己网站同款。那这时候就有人问了，你当时直接在 Trae 那时候，把笔记软件换成 Obsidian 不就可以了吗？但当时我说的是习惯问题，并且 Trae 也在越来越脱离我的习惯范围。如果我不早点更换代码编辑器的话，我还能继续用得顺手吗？更何况，我是换了以后才发觉 Codium 不适合写作啊！而且 Obsidian 本来就是我习惯的范畴，我现在换了跟没换一样。因为用 Trae 之前我就用着 Codium，在 Trae 之前我就用着 Obsidian。甚至当时用 Linux 的时候还极端一点，用 Vim 写文章的。今年年头哪个网站不就用 Vim 写的文章咯，Vim 在 Linux 下写文章也不算什么事情，Linux 的终端是令人习惯的。

Obsidian 现在很明显比我之前用的时候顺手多了，越来越接近一个商业软件有的感觉了。像是右下角能看到字数、笔记能编辑 Frontmatter、能做数据库看笔记视图这些东西，也都比以前我刚用 Obsidian 时“啥也不会，啥生态也没有”要强。我才发觉 Obsidian 的数据库是真的好用，替代默认的笔记文件列表作为笔记展示页的话，我可以按照自己的习惯，能很快地找到那篇文章，因为一切都是跟我的网站一样的。数据库有一个卡片样式，封面能使用 `cover` 的，名称能用 `title` 的。我当然不是直接把网站目录，作为 Obsidian 的仓库目录。而是桌面新建一个笔记目录，把自己的这些文章和图片都放进去，按照文章里面的路径依赖重新排序好。

我以前有个 AI 插件用着特别顺手，我记得建立简洁博客那时就是用它写的文章。当然我现在用不上那个 AI 插件了，貌似那个 AI 插件不能编辑笔记的 Frontmatter，只能回答和产出笔记的正文部分。况且每次写文章、扩写文章都得需要重新写一遍提示词，我的这些 AI 应用都是提前写的好的提示词，等需要批处理的时候就批处理，而不是有个对话框让我重写提示词，应该没程序员喜欢反复写提示词的，要不然就不会有 Skill 了。反正无论什么工具，适合自己、用着顺手就行了，反正就是让自己开心嘛！写文章的时候收到了 DeepSeek 的邮件来信，他们说自己的 API 支持搜索了，每 1000 次搜索成功就是 5 块钱。听着也不是很贵之类的，但 Aider 能指定网页的内容啊！
