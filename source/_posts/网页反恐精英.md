相信大伙只要是小时候接触电脑的，多少玩过《红色警戒》、《反恐精英》这类电子游戏。我虽然是 2009 年才出生的，但这些游戏我玩过类似的。前者对应本博客以前提过的《0 A.D.》，后者则是我从玩到大的《反恐精英：全球攻势》。这里只是说明我本人的电子游戏浓度，不代表我本人就只玩过这些。最近有个和朋友一起玩《反恐精英》老版本的需求，但我并不了解这款游戏。我对《反恐精英》作为《半衰期》模组的历史其实并不太懂，只是知道当时能玩到的《反恐精英》是一个运行在《半衰期》上的模组。重要的是很多网页副本和离线版让我以为这游戏是免费的，就像后来游玩的《反恐精英：全球攻势》那样，当知晓这件事的时候我又花了 40 块补了《反恐精英》的正版，最后得到了这款游戏的本体包。那这和本文的标题有啥联系呢？你等会就明白了。

如果你想本地部署一个《反恐精英》网页版，我目前用的项目是 `modesage/cs1.6-browser`，它是一个只提供了游戏引擎的网页版本《反恐精英》，它需要一个正版的游戏本体包作为前置依赖。部署好访问机器的 8080 端口就能玩了，别人也能访问这个端口打开《反恐精英》，大伙都可以在你这里玩上《反恐精英》。不过受限于浏览器的体量和操作方式，玩起来可能并不舒服，但这样也比直接玩原版的包舒服很多。原版《反恐精英》因为历史上的技术性原因，用的是隐藏鼠标加不断重置鼠标位置做的转头，现代浏览器则可以向系统申请鼠标指针的捕捉权限，没有那么别扭。但是我所用系统不方便运行脚本目录 32 位的 SteamCMD 脚本，怎么解决它呢？我只需将 Mac 上 CrossOver 的 Steam 目录下《反恐精英》游戏本体包拷贝给这个项目就可以了：

```zsh
git clone https://github.com/modesage/cs1.6-browser ~/Downloads/
cd ~/Library/Application\ Support/CrossOver/Bottles/Steamshare/drive_c/Program\ Files\ \(x86\)/Steam/steamapps/common/Half-Life/
zip -r ~/Downloads/cs1.6-browser/valve.zip valve cstrike

cd ~/Downloads/cs1.6-browser/
python3 -m http.server 8080 # 或者 npx serve -p 8080
```
