想起来曾经网上很多人都说：“编程的一些专业用语其实并不需要翻译成中文，甚至有一部分没法翻译成中文！”他们举例的就是 Cookies、P2P，还有一部分的英文缩写，公然嘲讽那些主张翻译的。反方也有话说的：“将这些词语翻译成中文，并在日常用语中替代，以便于那些不接触编程的普通人群理解，同时也方便一些新手程序员对于这部分技术的‘望文生意’！”他们举例的就是各种翻译好的专业术语。为什么突然想起这个呢？最近上网的时候，突然见评论区提起了“词元”和 Token 的关系，这是最近国内的权威媒体给出的建议：“Token 的普及化日益，需要从中文抽出一个词去翻译 Token 这个舶来词。”

这就吸引来了很多天生喜欢看乐子的程序员，你能看到，有人嘲讽翻译成中文是不切实际的，有人则在评论区快速玩起了梗。你完全不需要去理解为什么翻译成“词元”，因为你压根就不需要去理解。其实如今电脑产品圈子的气氛，跟《我的世界》的游戏现状很像：大佬已经到了能创造世界的地步，而入坑者依然像星期五一样。理由也和《我的世界》一样，他们没经历过大实况时代，新程序员也没经历过大机构时代。这就造成了一定程度的断代，很多老程序员认为只要是人就都会电脑，电脑是人最基本要会的一项技能。但你总能在社交媒体看到，有人压根就不熟悉按键操作，很难是因为他傻，他成年了才接触电脑。

你可能就会问了，为什么我在这里用的是很难，并非他完全是？其实对于那些不接触电脑的那些人来说，他们在现代社会完全是能活得下去的，只不过原本替代他们电脑生态位的那个东西叫做手机。他们确实拥有最基本的成年人思维，也知道手机要怎么样换字体、买主题、剪辑、修改图片、写文章。就像我在不熟悉编程以前，选择写文章的工具也不是啥 HTML 编辑器，只是从应用商店里下载了一个 WPS 到手机上。只是对他们来说，电脑象征着另外一套语言，如果要学习电脑，必然要改变自己而已。他们并不是那么需要电脑，因为他们完美避开了跑模拟实验、电子竞技、信息技术等一系列需要电脑才能去做的工作。

不妨现在就去刷刷短视频，你依然能看到很多程序员博主，不在自己的博客站上更新，依然能看到很多小博主在社交媒体更新。尤其是幸幸苦苦写的稿子不发在网站、专栏，而是又花了一倍时间做成视频发在自己的账号上。看到了吗？这就是一种非常典型的“定式思维”。对你来说抖音明明是一个视频网站，在上面发文章这一件事很别扭，但就是有人愿意在平台上兢兢业业地写文章，只求有人来看，而不是发在博客园或者自己的网站。或许对于他们来说，这并不是很鹤立鸡群，毕竟抖音本来就做了发文章功能，你可以在上面发长文、短评，还能把自己的说说做成小卡片配上音乐，而不是简单文字配上难看网页背景。

看到了吗？对于你来说，你处于一个上帝视角的怜悯位置；但对于他们来说，在平台上发文章就是传播自己思想最快的途径。这些文字……我的意思是说，或许我们处于的位置不一样，所以想到的也不一样。这意味着并不是 Cookie、P2P 无法被翻译，你完全知道厂商常用的“端到端”就是 P2P，也知道其实 Cookie 就是网站递给自己的令牌。或许是知识的诅咒，对你来说这玩意不需要翻译也能懂，你处于那个位置太久了。其实 Token 也可以被翻译成中文的，只是因为你觉得懒没必要而已。但它也不应该是“词元”，你要知道的，Token 不仅是你从厂商买的 AI 余额，它和 Transformer 中的 Token 是一回事。

厂商的按 Token 收费只是一种计费模式，如果翻译成词元外人反而更不清楚……我是说，或许它不应该被叫作“词元”，而是应该被叫作“词根”，如果你要更准确点来说，那就应该是翻译成“语义词根”。这或许只是我个人的简单译法，毕竟你想想看，“我花钱买语义词根给 AI 用”、“按每百万语义词根缓存收费”还有“所谓 AI 理解并预测的，就叫语义词根”等情境下的这几句话，其实说起来和听起来还挺顺口的。或许这只是我的一厢情愿吧！但无论如何，这个翻译对我来说，已经足够有理由替代 Token 了。我现在脑子里会无意识地想到“词根”，或许正是说明了 Token 翻译成“词根”的合适性对我来说接受度有多高。
