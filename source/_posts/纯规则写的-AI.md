大家好啊，欢迎来到我的博客网站。这次看到这个标题，是不是被说得一愣一愣的？缓过神来，这不就是规则系统嘛，我们都熟悉是吧？早年的 QQ 机器人，还有我们电脑上的 Siri，都是零权重的规则问答系统——你把规则写在那里，Siri 或者 QQ 机器人回答问题的时候，就是按照词典和解析方式去寻找答案的，这次给大伙带来最新的科技圈成果。它是由一位大大使用 DeepSeek 牵头，一群大语言模型“蜂群”做的超 50 万行的规则零权重 AI。听介绍也是非常吓人，据传它的能力已经能追平一些小模型了，并且问答胜率能到 26% 左右。当然，这些都是我看视频得知的，我本人也没有什么专业的设备去测量这个东西。那我们就来说一下这个 AI 如何开箱，以及开箱体验吧。整体也非常简单：

```zsh
git clone https://github.com/huggingface/pybot ~/Downloads/
cd ~/Downloads/pybot
python3 -m pybot
```

这时候就有人问了：“博主博主，那下一步是什么呢？”没有下一步了，部署就这么简单了。它是一个没有任何权重的 AI，也不需要准备任何类似 Ollama 这样的运行环境，你直接这样运行就行了。它只是一个代码数量超过 50 万行的规则判断系统。这倒让我想起一些东西。不是它究竟有多智能、现在的 AI 有多神奇，我想到的是昆虫神经系统。像野外那些昆虫，它们身上的指挥中心，也就是控制系统，就跟这个很像。最让我记忆深刻的就是蟑螂的控制系统，我以前以为这套东西是有自我意识的，但是长大后我才知道，蟑螂只不过是按照自己微弱的神经系统去做一些随机判断，包括它想走的路径都是随机的，整天漫无目的地随机乱爬。都是基因写死的，只为了完成一件事情，那就是生存下去。

实际上手体验了一下，发现效果其实也还不错。毕竟它是一个问答规则系统嘛，最起码能知道我叫什么名字，并且也能像打招呼一样向我打招呼。整个麦克运行起来也没有任何压力，跟普通的大语言模型有很大的差别了……毕竟它是一个零权重的问答系统嘛，只是 AI 牵头开发的穷举问答小软件而已，你也不能给它有多大的要求，就当作是个玩具看待吧！那不得不说啊，现在的科技发展也是非常迅速啊，都轮到大语言模型给自己生小孩子的时代了……当然，我可不希望以后在电商平台想投诉的时候遇到的是这种东西。遇到这种东西，那还不如不投诉得了，是吧？那我还是宁愿遇到一个能够听懂我说话、会敷衍我的大语言模型啊，它至少能够给我一点希望，而不是一个只会按照词典回复我的机械小虫子啊。
