今天是星期几？我还以为是星期四了，结果我妈居然说明天是星期三，看手机上说确实是星期二。我以为自从我重装系统以后，已经过去好一段时间了，结果才只是过去一天而已。散步的时候突然聊起来了广州怎么样，我妈说我上次去广州不开心是因为遇到了不高兴的人，但我突然想说自己是因为没有带乌龟去才不高兴的。聊到了去广州到底去了几次，我妈说是四次，我笃定说是五次。我妈的逻辑是：我们是隔三年去一次广州的。但我却说：“那你怎么解释我们第一次去的是招待所，第二次去的是有电梯那个，第三次又回到了招待所，第四次去的是七星酒店，第五次去的是薏米酒店呢？”

第一次去广州还是在我很小的时候，记得当时还是在幼儿园，去那边住的就是招待所。第二次去广州因为姑妈提前预定了酒店，所以就住的是有电梯的那个，依稀记得那里的灯是坏的。睡觉总会闪一下让人心烦。第三次去广州觉得上次的酒店不好，于是又回到了招待所住。第四次去广州住的就是七星瓢虫酒店，那里装饰得很漂亮。第五次去广州住的是薏米酒店，住一晚上房价贵得要死，这一次去广州玩并不是特别开心。我还记得有一次去广州的时候，因为住的酒店离牛奶专卖店很近，我妈就买了一箱风行牛奶，结果到离开广州的时候还没喝完，后面要回家就连同那箱牛奶一起带上火车了。

我记得每次去广州都会拍些照片回来，直接从照片里考正不就行了吗？一回到家我就跟妈妈翻找起了手机相册，因为之前我跟妈妈换了好几次手机，系统文件都同步了好几次，我的手机信息损失大，自然是以我妈手机的照片为主。我跟妈妈从手机最底部开始翻找起来，早期的一些老照片都是我自己拼拼剪剪的，因为以前第一次接触到我妈红米手机，觉得里面的功能特别好玩。小孩子的心思嘛，就是什么都觉得有意思的。但是翻找手机相册最早都只有 2018 年的，因为以前换手机的时候没想过把照片都同步了，所以丢失了一些老华为手机的照片，对于 2016 年的情况自然是没法考正的。

那就从 2018 年算起吧，一直往上翻还有 2019 年的照片，但 2019 年的照片相比较 2018 年的照片特别少。按道理来说只要人还活着就不可能不拍照，但关于 2019 年的照片实际只有那几十张，还有几张是我亲戚的。再往上翻就到 2020 年了，2020 年是疫情爆发的时候，里面有张我在五月份抱着老电脑的照片。但那只能证明我在 2020 年确实买了电脑，并且在上面学习了编程知识，并不能证明我当时玩电脑具体是在玩些什么。相册里还有很多类似这张不明所以的照片，甚至还有一张是动图的山河瀑布，时间线是相对比较早，但我却不知照片保存时在做什么，来自哪个软件。

我之所以记得那次我住的是七星酒店，很大原因是因为那次我遇到了一个精神病，上来就抱着我和我哥哥说什么“美女”，但事实上我是一个男孩子。并且那次离开广州前往火车站的路上，在银行门口遇到了一条会咬人的疯狗。如果没有这些事情，我可能根本记不起我当时住的是七星酒店，甚至不会记住具体位置。因为去广州也就寥寥几次，每次都会遇到值得回忆的事情：招待所的晴天、房间坏掉的灯、招待所的烂房间、七星酒店的屋子、薏米酒店的贵……关于那些具体在广州玩了什么、吃了哪家店的食物、晚上去了哪里喝糖水、看夜景我都记不住了。只记得有几次去了白云山，风景好。

但 2021 年到 2022 年之间依然存在着大量空差，这是为什么呢？原来是因为有次我不小心删了手机分身空间，导致那些原本躺在手机里的照片全都消失了；还有一次是因为我不小心退出登录了微信，导致我妈要重新注册账号。甚至我在 2021 到 2022 这两年又丢失了一台手机，又抢走了我爸的一台副机器，后面这台副机器又被我爸砸了导致照片清空。一个人在有手机以后，自然是使用自己的手机拍照了，肯定不会再依赖家长的手机了。也就是说我在这两年间，丢失了四次那段时间的照片，大到我跟同学一起去研学的照片，小到我在日常里随手截下的几张无意义《我的世界》截图。

但好在游戏视频我可以通过旧抖音找到，只是关于那时候的东西不多了。况且有一段时间我又是抖音、快手、哔哩哔哩几个软件换着用，用着用着觉得不顺心了又把账号注销了，而且我的快手账号好像还被误封过。如果再仔细想想网络账号的话，我以前还在爱奇艺录制过《我的世界》但游戏视频，后面爱奇艺从自媒体改成标准电视平台后，那些视频我也不确定还有没有。甚至于今年在创建博客网站的时候，前前后后删了重建好几次。那些文章、图片、评论，我也都没有保留。就拿最近的一次来说，我的哔哩哔哩账号，一开始是发布 SpeedyNote 相关的开发实况，后面又发了建站视频。

再后面就是发布自己在游戏本上的游戏视频，都是在 Linux 系统上录制的。甚至于说起 Linux 我还有个账号，只记得当时还在玩米哈游的二游，在 Linux 上还关注米哈游的《绝区零》，还参与开发了绳网论坛的客户端。甚至我还有很多无所谓的 GitHub 账号，就拿最近重装系统后登录 GitHub 这件事来说，你重装系统以后肯定是要登录账号对吧？但我登录到了另一个 163 邮箱上，并且另一个邮箱账号密码也一样。进去以后发现这不就是我以前还在玩崩铁那时候，在 Linux 折腾时创建的账号么？依稀记得当时特别喜欢流萤，用的是流萤的鼠标指针，名称和头像都是流萤的。

而且说起来 GitHub 和邮箱账号，我记得我还注册过一个更久的，因为那时从医院出来爱吃海苔，所以后面就改名和海苔相关的名字了。写这篇文章的时候我登录上了那个账号，发现居然未读那么多封邮件，还都是 Facebook。我想起来这个网易邮箱账号，当初是为了注册网易版《我的世界》随便填写的地址。我还记得自己的 Steam 账号都还绑定在上面，只不过去年的时候换绑到了如今的邮箱，因为那个号码不再用了，担心以后 Steam 登不上。细想之下我还有很多东西是快要忘记的，因为都过去那么多天没在想起了，而且当时我也没有固定的博客渠道，好多东西都是随风而去的。

因为当时做这些事情，我也没有多爱写日记。包括一张 2024 年 8 月的照片，照片只记得我和妈妈在雨后散步，但当时已经是买到游戏本的时候了。我只记得当时是我和妈妈在散步，并且我妈把我驼背走路拍下来了。我不记得这张照片是在哪里拍的，也不知道当时的自己在想什么。不像现在拍一张照都放博客上，拿一堆文字把它裱起来。地板是湿湿的石砖，只能告诉我是在雨天过后，后面的店铺背景是模糊的，不知道是在哪里。写这篇文章的时候，我还登录上那个 GitHub 账号看了一眼。头像瞬间把我拉回几年前离开学校平板编程、知乎发布视频的日子，注册时间是 2021 年。
