就在今天下午，我总算完工了我的全新博客友链 Pro Max 检测脚本，整个人感觉就像是沙袋倒我身上一样松了。我的旧脚本有很多问题，用的是系统自带的延迟测算指令，而不是像人一样去访问。这就造成了一个问题，事实上延迟检测依然是绑定 DNS 的，它会被解析到服务商自己的 CDN，这就意味着虽然它（网站）已经是死了，但依然有人在帮它传话，可是当你真去看一眼的时候，它已经嘎巴躺在那了。针对这种问题，Playwright 给出了很明确的解决方案——让程序用浏览器的视角去看看。如果能够访问，则该网站不是坏了；如果不能访问，则该网站是坏的。这就是很普通的运行逻辑，大伙都能懂。

值得一提的是，整套代码我并没有沿用以往那套，友链检测脚本中的“某人的网站可以访问”这种日志。我直接使用的是黑名单，也就是说当你的网站无法被访问的时候，才会出现在日志里面。为此，我特地刷新了我的浏览器缓存，下载了一个全新的 Playwright Chromium 浏览器。这样，它就能跟我的 Brave 版本对上号了：它能访问的，我都能访问；我不能访问的，它说不定也不能访问。因为它不会输出任何其他日志，所以大部分情况下都只能看到一个空的框，你可能会以为它是卡了，其实并不是这样的。很快，经历了漫长的轮询以后，程序给出了我两个答案：“冷月苼寒”和“兔兔”，他们的站挂了。

我原本想的是，网站挂就挂了吧！我发送一封邮件，告知他们的站长就是了，顶多结束了不就回复我一句“谢哥！”，要不就是石沉大海，也不是什么很奇怪的事情。于是我发给了冷月苼寒的站长夏雨，以及兔兔的站长。发完这些邮件以后没什么响应，于是我就去忙自己的事情了。对我来说，我更应该做的是陪伴家人、打游戏，于是我就去外面散步了。跟母亲去商场买了一些饼干，明天初一拜神的时候要用。我买了些方便面，今晚能当夜宵吃。回到家后打开电脑，我才看到这两封邮件，兔兔的邮件非常简短，就只是说了自己重启了服务器。而夏雨的邮件就有点长了，连着发了很多封带图片，信号差没下载干净。

因为图片烂在那也不知道他说的什么，所以就只好去看他的文字了。他说他那边访问没什么问题，叫了几个朋友去访问了，还问我能不能把图片发给他，告诉他我这边是什么情况。这时候我还没在意什么，只觉得是对方有一些急，于是就把图片和信息来源都发给他了，并告知了对方我是怎么发现他的网站访问不了的。结果对方突然激动，一连着发了很多封，还说操作不方便，要联系方式。对我来说其实联系方式不算什么，因为我的 QQ 本来就全都是陌生人，我的主战场在微信。于是我就直接加上了他的 QQ，向他说明了网站的问题。我可以注意到对方发的速度有点快，我依然没在想什么，只当是个人习惯。

他说他的网站 CDN 是好不容易申请到的，又说是什么什么白云山政务线。他还问我的网站是什么架构，我的网站还能是什么架构？一直都是 GitHub Pages 加 Cloudflare Proxy 打配合。以前使用过 Vercel，当时还夸 Vercel 是怎么好，但后面经历过 Vercel 的路径风波，就尝试 Cloudflare Pages 去了。Cloudflare Pages 本身也还行，但就是需要 Wrangler 去上传构建好的网站。考虑到 Wrangler 上传网站依赖网络，以后网站注定是很膨胀的，我不可能每天真的去浪费 1GB 的流量去上传网站，所以最后选择 GitHub Pages 去了。因为 Git 按差异上传改起来容易点说。

其实到这里我的情绪还是很平稳的，因为我已经 17 岁了。至少不是那种乱在互联网上发疯的小孩，其实我在现实生活中是很少说话的，不像我在博客中动辄写一千字以上的文章，看起来就好像我这人说话很有水平。中途我在处理兔兔那边发过来的网络消息，也就是说，此时的我是在双线并行的。我一直都习惯双线并行，因为以前我需要一边查资料，一边去修改 Linux 编译的参数，才能把 Gentoo 系统成功安装好。就在我想更仔细地去查询网站的情况时，对方突然就发了一大段话，属于是那种越看越生气的话。他的朋友都能访问，一会又说他也是干 IT 的，能不知道测速吗？强调自己网站开政府路由。

个人认为我生气的原因，并不是我聊什么东西聊急了，也不是干什么东西容易发火。我是属于对一个细节特别紧抠，甚至对自己的时间也特别保管的那种人，所以我很讨厌别人浪费我的时间。对我来说，我个人其实并不在乎你的网站到底是什么政务线路，还是什么乱七八糟的线路。因为那些东西跟我没有半毛钱关系，我又不是那些网站的站长，我用的 Cloudflare 就已经很稳了，静态页面不需要担心访问问题。我其实已经很尽到责任了。因为你的网站如果真的坏了，它的 SEO 会掉，就会影响到我的网站。因为搜索引擎的连坐机制，它不是看你网站怎么样，它是看你网站有没有挂着一个死链，就是那么简单。

就这点而言，无论你是所谓的政府线路还是什么所谓的第三方线路都好，你是薅羊毛蹭到还是花了时间怎么样的也罢……只要我无法访问，只要搜索引擎无法访问，那么我的 SEO 是必掉的。更何况，当初是你主动来我的网站，向我推荐你的网站，要求我加你网站的友链。并不是说，我跑到你的网站下去问你的联系方式，然后加了你的友链。所以我通知你是真的很有义务的，不是什么所谓的浪费时间。更何况当初你维护个网站都要发一封通知邮件给那些你所谓认识的人。发邮件不用密送而是用多个收发人，认识的不认识的都看到了我的邮箱，我都没有追究这个问题（因为影响不大），我现在只追究你网站的问题。

你这么在意友链的一个人，我怎么能私自把你的友链撤下来呢？我肯定是发一封邮件通知你。它是一个邮件，没有讲究时间、也不讲究什么时段。你随时都可以点进去看，又不是微信、QQ 那些，要发了你一定要看的。我用我最宝贵的时间去提醒你网站出了问题，本质上就算我没有你的友链，我也算是一种关心你的行为。结果你浪费了我的时间发了一大堆话没时间看，要去处理别的事情。给人感觉就像是你要吵起来了一样，你不像是证明你的网站没有挂，你是想向我说明你的网站没挂。既然你自知你是政务线路也好，那你为什么要跑到一个在乎个人 SEO 的站长面前，不说清政线容易问题的情况叫他加友链？

你难道就没有发现一丁点不对的地方吗？你说你的那些朋友开着代理都能进，但你有没有考虑过：其实那些加你友链、访问你网站的人，压根就懒得开代理，或者说他们压根就没代理可开？我向你反馈你的网站挂了，不就是因为在很多人没开代理的情况下，你网站确实不能进吗？这有什么不对的地方吗？代理这种东西就一定要开吗？难道我不开代理、不访问 GitHub，我就不能算是程序员了吗？我从始至终就没在意，没问过你是干什么 IT，你是什么政务 IT 什么乱七八糟的之类的，我甚至都没问过你，大学读的是什么专业、上的是哪个学校。我从始至终在意的只有那一件事，就是：你的网站能不能访问。

你甚至还向我解释什么运营商，什么大墙小墙……但那都关我屁事啊！我难道不知道什么网站开的代理不能进吗？要论开代理的话，为什么我不每天都开着洋葱代理呢？那样连暗网都能进。在我看来你就是浪费了我的时间，让我发火的家伙，还让我的脑子里充满了容易发火的肮脏东西。难道我的网站就不是国外服务器吗？难道我的网站就用的不是经常容易出问题的 CDN 服务商吗？国外服务器是很值得被拿来说事的东西吗？各家网络网站情况不一样你别发给我不就行了吗？我并非是不会生气的人，我只是不想破坏我们之间的友谊，它或许你对你来说一文不提，但对一个长期没朋友的人来说每一个朋友都有价值。

这让我想起了今天中午刚起床，我爸就在房间外面不知道在骂着谁，我当时听了一肚子无名火。不是因为我不习惯，反而我每天“浸泡”在这种环境里，忍受着各种肮脏的言语和病毒，我只是单纯觉得这玩意很吵而已。
