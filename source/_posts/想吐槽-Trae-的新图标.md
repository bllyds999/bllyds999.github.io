我的读者们都知道，我现在用的编辑器就是 Trae。因为除了日常的终端需求以外，我还需要一个图形编辑器，而 Trae 是我之前下载了，但现在懒得去删的一款软件。简而言之就是，我已经习惯把 Trae 当作文本编辑器。像是日常写文章、做笔记等除了编程以外的需求，只要触及到写文字和编辑，我都会下意识打开 Trae，而不是打开 Vim 以及 Nano。这可能真的是自从来到了 macOS 上，这些图形化软件影响了我的习惯吧！大家都知道如果我想要在电脑上打开一个常用软件，就要到启动软件的页面去寻找这个软件的图标。我印象中一直记得 Trae 是深色的、上面有一个绿绿的表情的小图标，于是我就会下意识地按照这个大致样子去寻找它。

但是最近 Trae 更新了，早知道我就不更新好了：它更新以后，图标换了，还多了一个小浮窗。幸好这个小浮窗是可以关掉的，要不能关掉的话，我可能就要把它当豆包一样对待，直接从电脑上卸载掉了。但最大的问题是他把图标换了，我突然有一点不习惯这个新的软件图标，虽然说我知道他这个软件的大体界面都没怎么换，但我就是想找到这个软件的时候，需要话两秒从启动栏中瞄一眼，找到符合印象当中的那个软件。这就导致如果我想写文章或者写代码，每次我都需要在启动栏中像这样浪费些时间瞄一眼，寻找现在的这个 Trae 的新图标。我觉得我还是要花一点时间适应一下新图标才行，虽然我早就知道它最近更新了，但还是没有适应过来多少。

毕竟我从去年就一直关注 Trae 这个软件项目，从去年年底直到这段时间，我都在使用这个软件。虽然一开始下载它主要是奔着里面内置的 AI 编程去的，但后面它这个 AI 功能需要排队，就当作一个普通编辑器了。现在我都用不到软件内置的这些 AI 功能，我想要用 AI 都是用外置的 TUI、CLI 代码工具。因为软件里的编辑工具用起来并不顺手，还需要排队，而外面的工具是我真金白银花了钱买的，终端操作更加舒服。自从它开始排队以后，我都不想用它的 AI 功能了，哪怕它可以接入自己的 API 密钥。因为，我刚开始就是奔着免费去的，要不然我也不会去跟着互联网使用 iFlow 那种工具了，虽然 iFlow 至始至终，都比 Claude 要逊色很多就是了。

它现在在我电脑上的软件生态位置，就跟直接使用 Code 是没有任何区别的，只不过 Code 默认的界面并不好看罢了。如果我愿意花一点时间的话，等哪一天把 Code 给下回来，我没准还真能让它用上系统这些好看点的字体。其实我感觉我自己说了这么多也是白说，既然我已经非常讨厌这个软件了，那我现在为什么还用它呢？所以我决定等写完这篇文章以后，就把自己的编辑器换成 Code，再把一些 Code 的插件都给下载回来。其实我感觉我需要的不只是 Code，我需要的是 Codium。那我之后还是老老实实用 Codium 得了，反正里面又没有我最讨厌的那个 AI 功能。之前不用 Code，就是觉得 Code 里面那个 AI 功能挺别扭，国内地区根本用不了的。
