7 月 3 日，我这正感冒，脑子昏沉得跟一团浆糊似的，寻思着刷会儿抖音缓缓神。毕竟我这信息茧房，可是花了整整一年，跟伺候祖奶奶一样精心投喂出来的。里面清一色是猫猫狗狗、代码特效和冷门小工具，没争吵，没暴论，更没键政，纯粹得一尘不染，简直就是互联网最后一片净土。结果您猜怎么着？我拇指刚往下一滑，好家伙，迎面撞上一记社会主义铁拳——反噬面直接怼脸上了。平时那个只会慢悠悠给乌龟拍整活视频的无害博主，突然对着镜头义愤填膺，痛批动物保护法执行不力；编程博主怒骂国产软件接广，最后写了个我在 F-Droid 就能找到的中文文件转换……我那一刻差点把手机扔出去，不是，我这浆糊似的脑子，是经不起这么炸裂的刺激的呀。

尤其是这编程博主让我绷不住，因为他压根儿就不是我们这帮混博客网站老油条熟悉的那一类——那种靠硬核技术沉淀几个月才冒一次泡的扫地僧。这是一个崭新崭新、油光水滑的自媒体号，点进他主页一看，好家伙，作品数屈指可数，就 40 期视频。虽然第一期是 2024 发的，但全都透着一股 2020 年的馊味儿。内容翻来覆去就那么三板斧：第一，国产软件全是屎山，第二，直接给你推荐 GitHub，第三，Hugging Face 真香。推荐的全是那种烂大街到不能再烂大街的入门级东西，根本不是我之前天天刷到的那种狠人——那种每天甩你一个骚气网站，今天让你一键抠出矢量女神图，明天就能在线给你生成一个 AI 我的世界皮肤，让你感觉自己像个赛博上帝。

不是，哥们，你睁眼瞧瞧，现在他妈的都是 2026 年了！推荐 GitHub 这事儿，搁 2020 年那会儿，我们还在疫情时期上网的时候，确实能唬住一帮萌新，算是技术博主的入门必修课。可现在呢？GitHub 都被微软玩出花来了，只要是个入职程序员就知道去那抄作业。在一个人人皆知、连实习生简历上都敢写“精通 GitHub Actions”的时代，你居然还正襟危坐，一脸严肃地给推荐一个叫 GitHub 的宝藏网站？你这不叫技术分享，你这叫考古发掘。我真怕你下一句就要掏出一个 SVN 来跟我说这是未来的版本控制主流。你就别让我这个脑子跟浆糊一样的病人，硬生生被你逗到笑喷出来，扭成混凝土，顺带再笑你那三千个不明所以、大概率是买来的点赞了。

我可不是那种食古不化的老古董，非要拿什么深度门户网站文章来踩短视频的水面浮沫。我也明白，碎片时间嘛，图个乐子就得了。可问题是，如果我刷短视频，图的就是那一瞬间颅内高潮的小惊喜，结果你系统给我推这种陈年馊饭、毫无营养的垃圾玩意儿，那我瘫在沙发上发呆、盯着天花板数裂纹的意义何在？我头昏脑涨，不就是为了看点能让我暂时忘记药苦的东西吗？往后哪怕系统给我推一段别人从外网哪个犄角旮旯搬运来的、画质糊成马赛克的泰拉瑞亚通关实况，或者干脆就是一只橘猫在纸箱里拉屎，我都觉得那是一种恩赐，胜过眼前这茬打着“科技”旗号实则侮辱我智商的工业废料。真的，求求算法了，在我生病的时候，给我留条活路吧！
